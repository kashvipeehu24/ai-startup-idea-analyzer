# AI Startup Idea Analyzer

## Idea

AI Startup Idea Analyzer is a Python-based application that helps users organize and evaluate startup ideas by collecting information about the problem being solved and the target audience.

## Features

* Collect startup idea details
* Capture problem statements
* Identify target audience
* Display a structured idea summary

## Technology

* Python
* Git
* GitHub
