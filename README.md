# AI Startup Idea Analyzer

## Overview

AI Startup Idea Analyzer is a Python-based application that helps users evaluate and compare startup ideas. The application collects information about a startup concept, analyzes key factors such as market size, competition, and development cost, and generates scores to assist in comparing different ideas.

## Features

* Add startup ideas
* Store multiple startup ideas during runtime
* View all startup ideas
* Compare startup ideas
* Calculate risk scores
* Calculate profit potential
* Generate overall startup scores
* Identify the best startup idea

1. Clone the repository
